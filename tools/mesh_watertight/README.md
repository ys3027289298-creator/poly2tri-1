# mesh_watertight — 网格水密性检查与修复

打印前发现网格有缝、肉眼又查不出来时的自检工具。纯 Python 3 标准库，无第三方依赖。

## 工作流程

1. **顶点焊接**（可选，`--weld-eps`）：合并间距小于 eps 的重复顶点，闭合因顶点重复造成的发丝缝（最常见的"看不见的缝"）。
2. **边配对**：水密定向流形上每条无向边恰好被两个三角形以相反方向引用。只出现一次的是边界边；出现两次但同向的是朝向冲突；超过两次的是非流形边。
3. **边界环提取与判定**：把边界边链成闭环，计算每个环的绕序（Newell 法向量 + 投影有向面积）、周长、跨度（包围盒对角线）和面积；面积近零的环判为退化（不可闭合）。
4. **自动补面**：跨度 ≤ 阈值的缝用质心扇形三角化填补，填充三角形与边界边反向缠绕，保证修复后整体朝向一致。
5. **单独报告**：真洞（跨度超阈值）、退化环、非流形边、朝向冲突只报告、不改动。
6. **修复后复验**：对修复结果重新做完整水密性校验，结果写入报告。

## 用法

```bash
# 只检查（水密退出码 0，否则 1）
python3 watertight.py check model.obj --weld-eps 1e-6 --report report.json

# 检查并修复（补面阈值默认取包围盒对角线的 5%）
python3 watertight.py repair model.obj -o fixed.obj \
    --weld-eps 1e-6 --gap-threshold 0.5 --report report.json
```

JSON 报告包含每个边界环的顶点、绕序、面积、跨度、分类（gap/hole/degenerate）与处置（filled/reported），以及修复后的复验结果。

## 测试

```bash
python3 test_watertight.py
```

覆盖四组网格加一个发丝缝用例，所有期望值均为手工推算：

| 用例 | 构造 | 期望 |
|---|---|---|
| 闭合 | 4×4 细分立方体（98 顶点 / 192 面） | 水密，零误报，修复为零操作 |
| 单缝 | 删 1 个内部三角形 | 1 个 3 顶点环（周长 h(2+√2)，面积 h²/2），补面后水密 |
| 多缝 | 删 3 个互不相邻三角形 | 3 个环全部补面，修复后水密 |
| 真洞 | 删 2×2 四边形区域（8 三角形） | 1 个 8 顶点环（周长 8h，面积 (2h)²）判为 hole，只报告不填补，网格保持不动 |
| 发丝缝 | +x 面顶点以 1e-7 偏移重复 | 焊接前检出缝的两个唇缘环，焊接（eps=1e-6）后水密 |
